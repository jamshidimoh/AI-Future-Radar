# G5 — Cross-Domain Convergence

Status: IMPLEMENTED — VALIDATION PENDING

G5 identifies deterministic convergence between distinct technology/intelligence domains. It requires cross-domain evidence and independent sources; lexical overlap alone is insufficient.

## Evidence model

A convergence record combines shared claim IDs, shared conceptual anchor tokens, domain diversity, and independent source diversity. Supporting and contradictory claim provenance remains represented in the upstream G3 evidence graph.

The convergence score is deterministic and decomposed into claim overlap, anchor overlap, domain diversity, and independent-source diversity. Weak pairs are rejected by a configurable threshold.

## Scope

G5 is analytical and publication-decoupled. Its default configuration is disabled. It does not change editorial ranking, selection, quotas, Telegram delivery, or the publication contract.

## Non-goals

G5 does not implement foresight/scenario construction or controlled production integration. Those belong to later gates.
