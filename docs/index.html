ثبت واکنش و کامنت

نظرات در GitHub Discussions ذخیره می‌شوند؛ بنابراین سابقه گفتگو، پاسخ‌ها، واکنش‌ها و مدیریت محتوا در همان مخزن باقی می‌ماند. برای ارسال نظر فقط روی «ثبت نظر و گفتگو» کلیک کنید و با حساب GitHub وارد شوید.
چطور نظر بدهید؟
  1. روی «ثبت نظر و گفتگو» بزنید.
  2. در GitHub یک Discussion جدید ایجاد کنید یا به گفتگوی موجود پاسخ دهید.
  3. نظر خود را درباره یک خبر، مصاحبه، منبع، تحلیل یا اولویت سیگنال بنویسید.
  4. مدیریت و پاسخ به نظرات از داخل GitHub Discussions انجام می‌شود.
